# Quad

Минималистичный десктопный плеер: подключаешь музыкальные аккаунты и слушаешь всё в одном месте.

Сейчас работают Яндекс Музыка и SoundCloud: поиск, медиатека и волна переключаются между ними или смешивают их. Spotify, Apple Music, YouTube Music и локальные файлы пока только в планах.

Оба сервиса подключены через неофициальный API, поэтому могут перестать работать без предупреждения.

Как добавить новый сервис, написано в начале `src/providers/index.js`.

## Что умеет

- Главная со стеной обложек и микс по всем лайкнутым трекам
- Поиск, карточки артистов и альбомов, медиатека с разделами плейлистов, альбомов и сборников
- Моя волна на собственном алгоритме: режимы, жанры, эпохи, волна от любого трека
- Кнопка «Не нравится»: трек больше не попадётся, вернуть можно в настройках
- Страница трека с текстом, который идёт под музыку
- Живой фон на волне и странице трека: искры, звёздочки и вспышки от самого звука, взрыв на дропе. Выключается кнопкой «Фон» на волне или в настройках
- Очередь, «играть следующим», скачивание треков со всеми метаданными, обложкой и текстом
- Эквалайзер и выбор устройства вывода
- Настройка внешнего вида: цвета, фон, размеры панелей и обложки

## Установка

Установщик для Windows лежит в разделе [Releases](https://github.com/egalalpp/quad/releases/latest). Подписи у него нет, поэтому Windows покажет предупреждение: «Подробнее», затем «Выполнить в любом случае».

При запуске приложение само проверяет новую версию и предлагает обновиться.

## Разработка

```bash
npm install
npm start
npm test
```

| Команда | Что собирает |
|---|---|
| `npm run package` | папку с приложением для Windows в `dist` |
| `npm run dist:win` | установщик для Windows в `release` |
| `npm run dist:mac` | dmg, запускать только на Mac |
| `npm run dist:mac-on-windows` | zip для Mac прямо на Windows |

Сборка для Mac на настоящем Mac пока не проверялась.

## Новая версия

Поднять версию в `package.json`, собрать `npm run dist:win` и выложить релиз с тегом `vX.Y.Z` и файлом `Quad-Setup-X.Y.Z.exe`. Приложения увидят его при следующем запуске.
